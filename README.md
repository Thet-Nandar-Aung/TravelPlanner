# TravelPlanner: Modular Multi-Agent Travel Assistant

##  Overview
TravelPlanner is a LangGraph-powered multi-agent system that helps users plan personalized travel itineraries using dynamic routing, tool-augmented reasoning, and modular agent design. It supports advisory, budgeting, loyalty analysis, and itinerary generation with ReAct-style planning.


##  Setup Instructions

### 1. Install dependencies
pip install -r requirements.txt

### 2. Set your OpenAI API key in .env file

### 3. Run the App
python3 -m app.run

### Sample prompt to test
Examples:
  • plan a 4-day Bali trip under SGD 2000 in June
  • 7-day Japan (Tokyo/Kyoto) in December for 2 pax, ~SGD 3500
  • 5 days in Paris this spring, food + museums focus, ~10000
